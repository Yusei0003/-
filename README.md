# 交通費 取りまとめアプリ

KESEN LARUS BASKETBALL CLUB の「交通費等及び謝礼金支給規程」第3条（練習活動）・第4条（土日祝日活動）に基づき、対象スタッフ5名（脇坂健吾・小山裕介・熊谷大輔・今野和倫・和田悠晟）への交通費を毎月取りまとめるための、ブラウザだけで動くシンプルなツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

審判・コミッショナーへの謝礼金、メインコーチの扱いは対象外です（別管理）。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. **入力タブ**: 日付と区分（通常練習／土日祝日活動）、土日祝日活動の場合はさらに活動場所・拘束時間を選ぶと、1人あたりの支給額が自動表示されます。出席した対象者にチェックを入れ「登録する」を押すだけで、チェックした全員分がまとめて登録されます
3. **一覧タブ**: 登録済みの記録をスプレッドシート風の表で確認・支給額の修正・削除。月や氏名で絞り込み可能
4. **月次集計タブ**: 対象月ごとに5名それぞれの月間合計と支払予定日（規程第9条：翌月25日）を表示

## 注意事項

- データはブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。
- 個別に金額調整が必要な場合は、一覧タブの支給額欄を直接編集してください。
