# 交通費 取りまとめアプリ

KESEN LARUS BASKETBALL CLUB の「交通費等及び謝礼金支給規程」第3条（練習活動）・第4条（土日祝日活動）に基づき、対象スタッフ5名（脇坂健吾・小山裕介・熊谷大輔・今野和倫・和田悠晟）への交通費を毎月取りまとめるためのWebアプリです。データはFirebase（Firestore）に保存され、共有の合言葉でログインした端末同士でリアルタイムに同期されます（PC・スマホなど複数端末から同じデータを見られます）。

審判・コミッショナーへの謝礼金は対象外です（別管理）。

## 使い方

0. `index.html` をブラウザで開く（GitHub PagesのURL、または `python3 -m http.server` 等で配信）。ログイン画面が表示されるので、共有の合言葉（Firebase Authenticationに設定したパスワード）を入力します。**`?key=合言葉` を付けたURL**（例: `https://.../?key=xxxxxx`）を開いた場合は、この入力なしで自動的にログインされます。LINEなどでリンクを共有する際はこの形式のURLを使うと、ブラウザの種類やアプリ内ブラウザかどうかに関係なく毎回確実にログインできます
1. **入力タブ**: 対象者を1人選び、区分（通常練習／土日祝日活動）を選びます。通常練習の場合は役割（スタッフ／メインコーチ）、土日祝日活動の場合は活動場所・拘束時間を選ぶと1日あたりの支給額が自動表示されます。参加した日をカレンダーでクリックして複数選択し（月をまたいで選択したままでも保持されます）、「登録する」を押すとまとめて登録されます。人ごとに月の実績をカレンダーから一括で入力するのに向いています。すでにその対象者の記録がある日はグレー表示・選択不可になり（マウスを乗せると登録内容を確認できます）、同じ日に重複して登録することを防ぎます
3. **一覧タブ**: 登録済みの記録をスプレッドシート風の表で確認・支給額の修正・削除。開いたときは記録のある最新月が自動的に選ばれた状態で表示されます。月や氏名で絞り込み可能（「すべての月」を選べば全期間を表示できます）
4. **月次集計タブ**: 対象月ごとに5名それぞれの月間合計・稼働率と支払予定日（規程第9条：翌月25日）を表示。
   - 「領収書をPDF出力」を押すと、その月に活動のあった対象者ごとに所定様式（交通費受領書）1ページずつをブラウザの印刷ダイアログに表示します。印刷先を「PDFに保存」にすればPDFとして保存できます
   - 「差込データをExcel出力」を押すと、これまでの全期間・全対象者の記録を「差込」シートと同じ列構成（No./支払月/名前/金額/メイン/サブ/土日各区分の回数/支払/確認）で.xlsxファイルとしてダウンロードできます（連絡先・住所の列は含みません）
5. **ダッシュボードタブ**: 対象年度（4月始まり〜翌年3月）を選ぶと、年間合計費用・総活動日数・活動月平均費用・稼働率トップの対象者を一目で確認できます。月別の費用推移、活動区分別（練習メイン/サブ、土日各区分）の費用内訳、対象者別の年間支給額・参加日数・稼働率をグラフと表の両方で表示します

## 封筒印刷（現金手渡し用）

月次集計タブの「封筒を印刷（対象期間を指定）」から、開始月・終了月を選んで「封筒を印刷」を押すと、指定した期間に1件でも交通費の記録がある対象者について、1人1枚ずつ長形3号封筒（120×235mm）の宛名面をブラウザの印刷ダイアログに表示します。

- 開始月と終了月に同じ月を選べば単月分、違う月を選べば「令和8年4月〜7月分」のようにまとめて数か月分の合計金額で出力できます（年度をまたぐ場合は「令和7年12月〜令和8年3月分」のように両方の年が表記されます）
- 記録が1件もない対象者の封筒は作成されません
- 印刷ダイアログで用紙サイズを「長形3号」（対応がない場合は「ユーザー定義」で120×235mm）に設定し、プリンタの封筒トレイ等にセットして印刷してください
- 宛名・金額を印刷する仕様のため、印刷後は手渡しの直前まで人目につかない場所で保管することをおすすめします

## 過去データのインポート（CSV）

月次集計タブの「過去データをインポート（CSV）」から、`date,name,category,role,location,duration,amount,note` の列を持つCSVファイルを読み込んで記録を追加できます。同一内容の記録は重複登録されません。

## 月別の回数から一括インポート（CSV）

日付ごとの出欠は覚えていないが、月ごとの回数（メイン・サブ・土日半日/全日×管内外）と金額だけは分かる、という過去データ用のインポート機能です。月次集計タブの「月別の回数から一括インポート（CSV）」から、以下の列を持つCSVファイルを読み込めます（「差込」シートと同じ列構成のファイルがそのまま使えます）。

`支払月,名前,金額,メイン,サブ,土日(半日・内),土日(全日・内),土日(半日・外),土日(全日・外)`

- 支払月は`R8.4`（令和8年4月）のような和暦表記で入力します
- 回数の列（メイン・サブ・土日各区分）の数だけ、規程どおりの単価で記録を自動生成し、その月内の日付に均等に割り振って追加します（実際の活動日ではない仮の日付になる点にご注意ください）
- 金額の列がある場合、回数から計算した金額と照合し、食い違いがあればインポート結果に表示します（食い違いがあっても記録自体は回数どおりに追加されます）
- 同一内容の記録は重複登録されないため、同じファイルを再度読み込んでも二重に追加されません

## 稼働率について

「稼働率」は、その月に1人でも活動記録があった日（＝練習または練習試合があった日）を母数とし、各対象者がそのうち何日参加したかで算出します（参加日数／活動日数）。金額の多寡ではなく、活動日に対する各人の参加頻度を見るための指標です。

## 領収書用の連絡先・住所の設定

月次集計タブの「領収書用の連絡先・住所を設定」を開くと、対象者ごとに受領書に載せる住所・電話番号を個別に入力できます。この情報もFirestoreに保存され、ログインした全端末で共有・同期されます（一度どこかの端末で入力すれば、他の端末でも入力し直す必要はありません）。

## データの保存先とログインについて

このアプリはFirebase（Firestore + Authentication）を使ってデータを保存しています。

- **データ本体**（出席記録・連絡先）はFirestoreに保存され、ログインした全端末でリアルタイムに同期されます
- **アクセス制限**: Firebase Authentication（メール/パスワード方式）の共有アカウント1つで全員がログインします。パスワード＝合言葉を知らない人はデータを閲覧・編集できません
- Firestoreのセキュリティルールは `allow read, write: if request.auth != null;` とし、ログイン済みのユーザーのみ読み書きできるようにしています
- **接続にはインターネット接続が必要です**（これまでのようなブラウザのみで完結するオフライン動作はできなくなりました）
- 設定値（`firebase-entry.js` 内の `firebaseConfig` とログイン用メールアドレス）は公開されて問題ない情報です。実際のアクセス制御はFirebase Authenticationのパスワード認証とFirestoreのセキュリティルールで行われています
- 合言葉（パスワード）を変更したい場合は、Firebaseコンソール → Authentication → Users タブから、共有アカウントのパスワードをリセットしてください

### 合言葉入りURL（LINE共有用）

`https://（GitHub PagesのURL）/?key=（合言葉）` の形式でURLを作ると、開いた瞬間に自動でログインされます。ログイン画面を経由しないため、LINEグループなどにこのURLを貼っておけば、誰でもタップするだけですぐ入力できます。

- ブラウザの種類（Safari／Chromeなど）やLINEのアプリ内ブラウザかどうかに関係なく、開くたびに認証されるため、「端末ごとに1回だけログイン」方式で起こりうる「アプリ内ブラウザだと保存されない」「別のブラウザで開くと未ログイン扱いになる」といった問題を回避できます
- ログイン成功後はURLから `?key=...` の部分を自動的に消すため、ブラウザのアドレスバーには合言葉が残りません
- 一方で、このURL自体が転送・スクリーンショットされると、それを見た人は誰でもデータを閲覧・編集できてしまう点にご注意ください。合言葉を変更すればこのURLは無効になります（Firebaseコンソールでパスワードをリセットしてください）

### firebase-bundle.js について

`firebase-bundle.js` は、Firebase JS SDKと `firebase-entry.js`（初期化コード）を [esbuild](https://esbuild.github.io/) でひとつのファイルにまとめたものです。外部CDNに依存せず動作します。`firebaseConfig` を変更した場合など、再ビルドが必要なときは以下を実行してください。

```
npm install firebase esbuild
npx esbuild firebase-entry.js --bundle --format=iife --platform=browser --minify --outfile=firebase-bundle.js
```

## 注意事項

- 個別に金額調整が必要な場合は、一覧タブの支給額欄を直接編集してください（領収書のPDFにもその金額が反映されます）。

## クラブロゴについて

`logo.png`（背景透過のKESEN LARUSロゴ）は領収書・封筒の出力に使用しています。差し替える場合は同じファイル名で置き換えてください。

## キャッシュ対策（アセットのバージョニング）

`.github/workflows/version-assets.yml` により、このブランチへのpushのたびにGitHub Actionsが自動的に `index.html` 内の `app.js` / `style.css` / `xlsx-writer.js` / `firebase-bundle.js` の読み込みURLへ `?v=YYYYMMDDHHMMSS`（UTC・push時刻）を付与するコミットを追加します。これにより、コード更新後にブラウザの古いキャッシュが表示され続ける問題を軽減します。GitHub Pagesの設定変更は不要です（Deploy from a branch のまま動作します）。
