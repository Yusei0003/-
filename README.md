# 交通費・謝礼金 取りまとめアプリ

KESEN LARUS BASKETBALL CLUB の「交通費等及び謝礼金支給規程」に基づき、スタッフ・外部依頼者への支給額を毎月取りまとめるための、ブラウザだけで動くシンプルなツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. **入力タブ**: 活動に参加するたびに、日付・氏名・区分（通常練習／土日祝日活動／帯同審判／コミッショナー）を選んで登録。規程に基づく目安額が自動計算されるので、必要に応じて支給額を修正して登録
3. **一覧タブ**: 登録済みの記録をスプレッドシート風の表で確認・編集・削除。月やる氏名で絞り込み可能
4. **月次集計タブ**: 対象月を選ぶと、氏名ごとの月間合計と支払予定日（規程第9条：翌月25日）を表示

## 注意事項

- データはブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。定期的にブラウザのブックマーク/データを消さないようご注意ください。
- 「弁当支給あり」「中止（開始前／到着後）」「クラブ関係者・保護者が担当」にチェックすると、規程の除外規定に基づき目安額が自動的に0円になります。特例（規程第8条）などで金額を調整したい場合は、支給額欄を直接編集してください。
