# 交通費 取りまとめアプリ

KESEN LARUS BASKETBALL CLUB の「交通費等及び謝礼金支給規程」第3条（練習活動）・第4条（土日祝日活動）に基づき、対象スタッフ5名（脇坂健吾・小山裕介・熊谷大輔・今野和倫・和田悠晟）への交通費を毎月取りまとめるための、ブラウザだけで動くシンプルなツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

審判・コミッショナーへの謝礼金は対象外です（別管理）。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. **入力タブ**: 対象者を1人選び、区分（通常練習／土日祝日活動）を選びます。通常練習の場合は役割（スタッフ／メインコーチ）、土日祝日活動の場合は活動場所・拘束時間を選ぶと1日あたりの支給額が自動表示されます。参加した日をカレンダーでクリックして複数選択し（月をまたいで選択したままでも保持されます）、「登録する」を押すとまとめて登録されます。人ごとに月の実績をカレンダーから一括で入力するのに向いています。すでにその対象者の記録がある日はグレー表示・選択不可になり（マウスを乗せると登録内容を確認できます）、同じ日に重複して登録することを防ぎます
3. **一覧タブ**: 登録済みの記録をスプレッドシート風の表で確認・支給額の修正・削除。開いたときは記録のある最新月が自動的に選ばれた状態で表示されます。月や氏名で絞り込み可能（「すべての月」を選べば全期間を表示できます）
4. **月次集計タブ**: 対象月ごとに5名それぞれの月間合計・稼働率と支払予定日（規程第9条：翌月25日）を表示。
   - 「領収書をPDF出力」を押すと、その月に活動のあった対象者ごとに所定様式（交通費受領書）1ページずつをブラウザの印刷ダイアログに表示します。印刷先を「PDFに保存」にすればPDFとして保存できます
   - 「差込データをExcel出力」を押すと、これまでの全期間・全対象者の記録を「差込」シートと同じ列構成（No./支払月/名前/金額/メイン/サブ/土日各区分の回数/支払/確認）で.xlsxファイルとしてダウンロードできます（連絡先・住所の列は含みません）
5. **ダッシュボードタブ**: 対象年度（4月始まり〜翌年3月）を選ぶと、年間合計費用・総活動日数・活動月平均費用・稼働率トップの対象者を一目で確認できます。月別の費用推移、活動区分別（練習メイン/サブ、土日各区分）の費用内訳、対象者別の年間支給額・参加日数・稼働率をグラフと表の両方で表示します

## 過去データのインポート（CSV）

月次集計タブの「過去データをインポート（CSV）」から、`date,name,category,role,location,duration,amount,note` の列を持つCSVファイルを読み込んで記録を追加できます。同一内容の記録は重複登録されません。既存の「差込」シート（Excelの月次集計データ）のように日付単位でない過去の記録しかない場合は、月間の回数から日付を仮に振り分けてCSV化することでインポートできます（実際の活動日そのものではなく、月内に均等に割り振った仮の日付になる点にご注意ください）。

## 稼働率について

「稼働率」は、その月に1人でも活動記録があった日（＝練習または練習試合があった日）を母数とし、各対象者がそのうち何日参加したかで算出します（参加日数／活動日数）。金額の多寡ではなく、活動日に対する各人の参加頻度を見るための指標です。

## 領収書用の連絡先・住所の設定

月次集計タブの「領収書用の連絡先・住所を設定」を開くと、対象者ごとに受領書に載せる住所・電話番号を個別に入力できます。**この情報はこの端末のブラウザにのみ保存され、コード（GitHubリポジトリ）には一切含まれません**（このリポジトリは公開設定のため、個人の住所・電話番号などをコードに直接書き込むことは避けています）。そのため、新しい端末でこのアプリを開いた場合は、この設定を都度入力し直す必要があります。

## 注意事項

- データ（出席記録・連絡先設定）はブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。
- 個別に金額調整が必要な場合は、一覧タブの支給額欄を直接編集してください（領収書のPDFにもその金額が反映されます）。
